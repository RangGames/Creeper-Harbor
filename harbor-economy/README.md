# Harbor-Economy 사용법

판매·시세·NPC 상점·우편함·수리·제작·경매장 모듈. 운영자·콘텐츠 디자이너용 요약이다. 설계는 CreeperWiki docs 20 7장.

## 플레이어 명령

| 명령 | 하는 일 |
|---|---|
| `/판매` | 판매 상자 (상자 GUI). 물고기를 넣으면 합계 견적이 바로 보인다 |
| `/판매 손` · `/판매 전부` | 예전 확인 화면 (손에 든 것 / 인벤토리 전부. 전부는 귀한 물고기 제외) |
| `/잠금` | 손에 든 아이템 잠금 켜기/끄기 |
| `/시세` · `/시세 <어종>` | 시세판 GUI · 한 어종 텍스트 |
| `/경매` · `/경매 등록 [가격]` · `/경매 검색 <이름>` · `/경매 내목록` | 경매장 |
| `/우편함` | 우편함 (하나씩 받기 · 모두 받기) |
| `/거래내역` | 내 골드·물비늘 원장 기록 (최근 200줄) |
| `/수리` · `/제작` · `/큰손` | 예전 그대로 |

## 판매 상자와 귀한 물고기 보호

- 위 5줄에 물고기를 넣는다. 아랫줄 판매 버튼에 마릿수와 합계가 보인다. 일괄 판매 미끄러짐도 반영된다.
- 판매는 `/판매`와 같은 트랜잭션이다. `FISH_SELL` 원장과 고유 ID 장부 `SOLD`로 처리되고, 실패하면 아이템을 돌려준다.
- **귀한 물고기**는 다음 셋 중 하나다.
  - `/잠금`이나 판매 상자의 Shift+우클릭으로 잠근 아이템. 아이템 PDC `harbor:item_locked`에 표시된다.
  - 고유 번호가 있는 어종
  - ★5 어종
- 귀한 물고기는 다음처럼 다룬다.
  - "모두 넣기"와 `/판매 전부`는 건너뛴다.
  - 상자에 직접 넣었으면 판매를 두 번 눌러야 판다.
  - "귀한 물고기 돌려받기" 버튼으로 되돌릴 수 있다.
- 잠근 아이템은 경매 등록도 막힌다.
- 어종이 아닌 아이템을 넣으면 다음 틱에 돌려준다.
- 창을 닫으면 남은 물고기는 인벤토리로 돌아가고, 넘치면 우편함으로 간다. 접속이 끊기며 닫히면 전부 우편함으로 보낸다. 이미 저장된 인벤토리와 겹치지 않게 하려는 것이다.

## 경매장

- 화면 배치:
  - 윗줄: 분류 6개 · 정렬 · 검색
  - 가운데 4줄: 등록품 36개
  - 아랫줄: 이전 · 내 경매 · 쪽 정보(검색어 지우기) · 거래 기록 · 다음
- 정렬: 최신 · 낮은 가격 · 높은 가격 · 마감 임박 · 높은 등급. 버튼을 누를 때마다 다음 정렬로 바뀐다.
- 검색: 입력 화면에 이름 일부를 적는다.
- 거래 기록: 내가 판 것(수수료·받은 돈·보류 여부)과 산 것을 탭으로 나눠 보여 준다.
- 등록 확인 화면에 개당 내 가격, 지금 최저가, 최근 `economy.auction.price_info_days`일 낙찰 평균이 함께 나온다.
- 낙찰·취소·만료 SQL과 원장은 바뀌지 않았다. 읽기 쿼리와 `V3__auction_history_index.sql`(산 것 조회용 색인)만 더했다.

## 시세판

| 경제 계열 스킬 | 시세판에서 보이는 것 |
|---|---|
| '시세 정보' 1랭크 | 모든 어종의 지금 계수 |
| '시세 정보' 2랭크 | 위에 더해 24시간 전 대비 ▲▼ 추세, 급변 어종 강조(빛남), 정렬(번호 · 상승 · 하락) |
| '시세 예측' | 위에 더해 다음 시간 예측 |

보합 기준과 강조 수는 `economy.market.board.flat · top_movers`로 정한다.

## 상점 · 우편함

- **NPC 상점 수량:** 좌클릭 1개, Shift+좌클릭 한 묶음, 우클릭 개수 입력. 가방이 차면 남는 것은 우편함으로 간다.
- **우편함 모두 받기:** 보류가 아닌 우편을 하나씩 같은 `CLAIMED` 트랜잭션으로 받는다. 가방이 차서 못 받는 아이템은 남겨 둔다.

## API

Core `CurrencyService.history(uuid, currency, limit)`로 원장 최근 기록(`LedgerRecord`)을 읽는다. 읽기 전용이고 메인 스레드에서 완료된다.
