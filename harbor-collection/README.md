# Harbor-Collection 사용법

도감·최대어 기록·항구 수족관·방류·개인 어항 전시 모듈. 운영자·콘텐츠 디자이너용 요약이고, 설계는 CreeperWiki docs 20 4장에 있다.

## 플레이어

| 명령 | 하는 일 |
|---|---|
| `/도감 [플레이어]` | 도감 (상자 GUI) |
| `/도감 보상` | 도감 보상 트랙 |
| `/도감 최근` | 최근 등록한 어종부터 보기 |
| `/기록` | 어종을 골라 최대어 기록 보기 |
| `/기록 <어종>` | 그 어종 기록 GUI. 콘솔에서 쓰면 채팅으로 나온다 |
| `/기록 <어종> 채팅` | 기록을 예전처럼 채팅으로 |
| `/수족관` | 수족관 진행 화면 |
| `/수족관 상태` | 상태 한 줄 |
| `/수족관 기부` · `/수족관 기부함` | 손에 든 한 마리 기부 · 기부함 |
| `/방류` | 손에 든 어종 방류 |

### 도감 화면

- **윗줄:** 전체 탭과 지역 탭이 있다. 지역 탭에는 그 지역의 누적 달성률과 막대가 붙고, 완성하면 반짝인다. 오른쪽 끝(별)은 보상 트랙이다.
- **아랫줄:** 페이지 이동과 다음 버튼이 있다.
  - 보기: 전체 · 미등록만 · 등록만
  - 등급: 전체 → 일반 … 신화
  - 정렬: 번호순 · 등급 높은 순 · 최근 등록순
  - 최근 등록 바로 보기 · 보기 초기화
- **어종 아이콘:** 등록 어종은 어종 모델과 내 기록·첫 포획 날짜, 미등록은 실루엣과 힌트다. 누르면 Dialog 상세가 뜬다.

### 보상 트랙

보상 지급은 예전처럼 자동이고, 이 화면은 보여 주기만 한다.

| 줄 | 내용 | 설정 |
|---|---|---|
| 1줄 | 누적 도감 칭호 | `collection.yml total_milestones`. 치장품은 Shop이 같은 이벤트로 준다 |
| 2줄 | 시즌 도감 버프 | `season_buffs`. 달성한 단계는 "적용 중" |
| 3줄 | 지역 완성(시즌 도감): 칭호 + 물비늘 | `region_complete` |

### 최대어 기록

- **리그 탭:** 1차 · 2차 · 전체.
- **TOP 10:** 이번 시즌 서버 상위 10명을 플레이어 머리로 보여 준다. 데이터는 전광판과 같은 서버 기록 캐시라 DB를 읽지 않는다.
- **내 기록:** 시즌 순위, 시즌·누적 최고, TOP 10에 들려면 몇 cm가 더 필요한지 보여 준다.
- **어종 고르기:** 누적 도감에 등록한 어종만 누를 수 있다.

### 수족관 진행 화면

- **윗줄:**
  - 지금 단계, 다음 단계 문턱까지의 기부율 막대, 남은 어종 수, 누적 점수
  - 단계별 문턱(필요 어종 수)과 버프
  - 기부함 바로 가기, 어종 필터(아직 기부 안 된 어종 · 기부된 어종 · 전체)
- **가운데:** 기부할 수 있는 어종이다.
  - 인벤토리에 있는 어종은 앞으로 오고 반짝인다. 누르면 기부 확인 화면이 뜬다. 처리는 `/수족관 기부`와 같은 확인 화면과 같은 트랜잭션이다.
  - 기부되지 않았고 내 도감에도 없는 어종은 실루엣과 지역 힌트로 가린다.
  - 어종마다 "내 점수 인정 n/상한"을 보여 준다.

## 설정

- **막대 칸 수:** `balance.yml collection.menu.bar_width` (제안값 10).
- **문구:** `messages_ko.yml`의 `collection.menu.*` · `collection.track.*` · `collection.records.*` · `collection.aquarium.menu.*`에 있다.
  - 단계 설명은 `collection.aquarium.menu.stage_note.<단계>`.
  - 스탯 이름은 `collection.stat.<스탯 키>`. 없으면 키를 그대로 보여 준다.
